Migraciones de Base de Datos
ℹ️
Las 4 migraciones fueron ejecutadas directamente sobre el proyecto de Supabase en producción (hrlqteczbwyjickradbt) mediante la Management API, usando el token de autenticación del dashboard.
00057_partners_contact.sql

00058_profiles_envio.sql
ALTER TABLE profiles ADD COLUMN IF NOT EXISTS envio_estado TEXT DEFAULT 'no_aplica' CHECK (envio_estado IN ('pendiente', 'enviado', 'no_aplica')); UPDATE profiles SET envio_estado = 'pendiente' WHERE subscription_status = 'activa' AND envio_estado = 'no_aplica';

✨
Feature nueva de alto impacto. Las preguntas del examen ahora pueden tener imágenes en cada opción de respuesta (A, B, C, D), además de la imagen ya existente en el enunciado. Esto es especialmente útil para preguntas de diagramas eléctricos y planos.
Admin
Componente de upload de imágenes por opción
Grilla de 4 slots (A/B/C/D) en el panel de admin. Cada slot permite subir, previsualizar y eliminar una imagen independientemente. Flujo: URL firmada → PUT directo a Storage → URL pública persistida en DB.

Sección 6
Imágenes en Comentarios de Comunidad
✅
El cambio más pedido de la sesión. Los usuarios ahora pueden adjuntar una imagen al responder una duda o comentar en trabajos. La imagen se sube inmediatamente al escribir el comentario (misma UX que los posts completos) y se muestra inline con lightbox al hacer click.
  • 1
    Upload inmediato: El usuario clickea el botón 📷 junto al input → se abre el selector de archivos → la imagen sube a Supabase Storage (bucket comunidad-media) → se muestra preview con spinner de carga.
  • 2
    Validación antes de enviar: Si la imagen aún está subiendo, el submit muestra error "Esperá a que termine de subir la imagen." El usuario no puede enviar un comentario con upload incompleto.
  • 3
    Persistencia: La URL remota se envía al Server Action createComment como campo imagen_url y se guarda en la columna nueva de la tabla comentarios.
  • 4
    Renderizado: Los comentarios que tienen imagen la muestran debajo del texto. El click abre el lightbox ya existente en el componente PostCard.

Sección 8
Bug Fix Crítico — Build Render
Fix
Module not found: 'resend' — Build fallaba en producción
El paquete resend (para emails transaccionales) había sido instalado y usado en el código, pero el package.json actualizado no había sido commiteado. Render no encontraba la dependencia al hacer el build.

Fix: Se commitió y pusheó package.json + package-lock.json con "resend": "^6.12.2" en dependencies. Commit: c6bd69e.
